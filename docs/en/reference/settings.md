## General

### `enabled`

- **Type:** boolean
- **Default:** `true`
- **Scope:** `resource`
- **Description:** Turn LinguaLens on or off for this workspace or folder. When disabled, hover and selection translation stop; existing cache is kept.

### `targetLanguage`

- **Type:** enum: `zh-CN`, `zh-TW`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `ru`
- **Default:** `"zh-CN"`
- **Scope:** `resource`
- **Enum values:**
  - `zh-CN` — Simplified Chinese
  - `zh-TW` — Traditional Chinese
  - `en` — English
  - `ja` — Japanese
  - `ko` — Korean
  - `fr` — French
  - `de` — German
  - `es` — Spanish
  - `ru` — Russian
- **Description:** Target language for translations. Detection skips text that already matches the target (see `linguaLens.*` cross-link).

### `detection.strictChineseVariant`

- **Type:** boolean
- **Default:** `false`
- **Scope:** `resource`
- **Description:** When the target is `zh-CN` or `zh-TW`, do **not** translate text that is already in the other Chinese variant (e.g. skip Traditional when targeting Simplified).

### `detection.minLength`

- **Type:** number (min 1, max 64, advanced)
- **Default:** `3`
- **Scope:** `resource`
- **Description:** Minimum character length before a fragment is considered for translation. Shorter text is skipped unless you use selection translate.

### `detection.targetRatio`

- **Type:** number (min 0, max 1, advanced)
- **Default:** `0.6`
- **Scope:** `resource`
- **Description:** If this fraction of characters already looks like the target language, the fragment is skipped (reduces redundant API calls).

### `detection.reliableMinLength`

- **Type:** number (min 1, max 500, advanced)
- **Default:** `20`
- **Scope:** `resource`
- **Description:** Below this length, language detection is treated as unreliable and the extension may skip translation unless confidence is high.

### `detection.skipPatterns`

- **Type:** array of string (advanced)
- **Default:** `[]`
- **Scope:** `resource`
- **Description:** Regular expressions; matching fragments are never sent to the model. Applied together with `linguaLens.*` cross-link.

### `selection.output`

- **Type:** enum: `auto`, `notification`, `document`
- **Default:** `"auto"`
- **Scope:** `resource`
- **Enum values:**
  - `auto` — Notification for short text, new document when long
  - `notification` — Always show a notification
  - `document` — Always open a new document
- **Description:** Where to show selection translation results. `notification` is fastest; `document` opens a scratch buffer when output is long.

### `privacy.exclude`

- **Type:** array of string
- **Default:** `["**/.env","**/.env.*","**/*.pem","**/*.key","**/*.p12","**/id_rsa*","**/secrets/**","**/.git/**","**/node_modules/**"]`
- **Scope:** `resource`
- **Description:** Glob patterns for files that LinguaLens will not read or translate (e.g. `.env`, keys, `node_modules`).

### `statusBar.enabled`

- **Type:** boolean
- **Default:** `true`
- **Scope:** `application`
- **Description:** Show the **译** status bar entry that opens the LinguaLens quick menu.

## Model & API

- **Type:** string

- **Scope:** `application`
- **Description:** OpenAI-compatible API base URL (must include `/v1`). API keys are stored per origin via **Set API Key**, not in settings. Quick access: [Settings panel](command:linguaLens.openSettingsPanel).

### `llm.model`

- **Type:** string
- **Default:** `""`
- **Scope:** `application`
- **Description:** Chat model id sent in API requests (e.g. `gpt-4o-mini`, `deepseek-chat`). Required for translation.

### `llm.stream`

- **Type:** boolean
- **Default:** `false`
- **Scope:** `application`
- **Description:** Use SSE streaming for interactive requests (hover, selection). Document batch translation stays non-streaming. See also `linguaLens.*` cross-link.

### `llm.extraBody`

- **Type:** object
- **Default:** `{}`
- **Scope:** `application`

### `llm.systemPrompt`

- **Type:** string
- **Default:** `""`
- **Scope:** `application`

### `glossary.path`

- **Type:** string
- **Default:** `".translate-glossary.json"`
- **Scope:** `resource`
- **Description:** Workspace-relative path to `.translate-glossary.json`. Up to `linguaLens.*` cross-link terms are matched per request.

### `glossary.maxTerms`

### `llm.temperature`

### `llm.extraHeaders`
