# Supported file types

- **Code**: comments and string literals via tree-sitter (with regex fallback).
- **Config**: YAML, TOML, JSON/JSONC/JSON5, INI, XML, properties, and `key=value` files.
- **Documents**: Markdown and plain text (paragraph-level segmentation).
- **Notebooks**: Markdown cells.
- **HTML/Vue/JSX**: selected attributes and text nodes.
