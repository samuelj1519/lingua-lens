# Getting started

1. Install the extension from a `.vsix` or build from source (`npm run package`).
2. Run **AI Translate: Set API Key** and enter your provider key.
3. Set `aiTranslate.llm.baseUrl` and `aiTranslate.llm.model` (see [Configure providers](../how-to/configure-providers.md)).
4. Open a code file, hover a comment, and wait for the translation block.
5. Open a Markdown file and run **Translate document (preview)** or use the status bar menu.
