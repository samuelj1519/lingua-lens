## CodeLens

Markdown/plain-text editors show **Translate document (preview)**, **Generate translation file**, and **Refresh document translation** at the top of the file. Wording comes from `l10n/bundle` (follows `linguaLens.targetLanguage`).

## Status bar

The **Tr** status item opens a QuickPick (enable/disable, target language, settings panel, translate document, …). The neighbor item shows the current `targetLanguage`.
