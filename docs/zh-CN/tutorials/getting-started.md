# 快速开始

1. 从 `.vsix` 安装，或克隆仓库后执行 `npm run package` 构建。
2. 运行 **AI Translate: 设置 API Key** 并填入密钥。
3. 配置 `aiTranslate.llm.baseUrl` 与 `aiTranslate.llm.model`（见 [配置 LLM 提供商](../how-to/configure-providers.md)）。
4. 打开代码文件，将光标悬停在注释上，等待译文块出现。
5. 打开 Markdown 文件，执行 **翻译全文（对照预览）** 或使用状态栏菜单。
